# ZEPTO INSIGHTS

## 📌 PROJECT OVERVIEW

**ZEPTO INSIGHTS** IS A SQL-BASED E-COMMERCE DATA ANALYSIS PROJECT BUILT USING **POSTGRESQL**.

THE PROJECT ANALYZES ZEPTO PRODUCT DATA TO UNDERSTAND **PRODUCT PRICING, DISCOUNTS, INVENTORY, STOCK AVAILABILITY, PRODUCT CATEGORIES, AND POTENTIAL REVENUE**.

THE MAIN OBJECTIVE IS TO TRANSFORM RAW PRODUCT DATA INTO USEFUL **BUSINESS INSIGHTS** USING SQL, STARTING FROM DATA EXPLORATION AND CLEANING AND MOVING TOWARDS ADVANCED ANALYTICS.

---

## 🎯 PROJECT OBJECTIVES

- EXPLORE THE ZEPTO PRODUCT DATASET.
- IDENTIFY AND HANDLE MISSING VALUES.
- REMOVE INVALID PRODUCT RECORDS.
- CONVERT PRODUCT PRICES FROM PAISE TO RUPEES.
- ANALYZE PRODUCT CATEGORIES.
- IDENTIFY IN-STOCK AND OUT-OF-STOCK PRODUCTS.
- ANALYZE PRODUCT DISCOUNTS.
- CALCULATE CUSTOMER SAVINGS.
- ESTIMATE CATEGORY-WISE REVENUE.
- ANALYZE PRODUCT VALUE BASED ON PRICE PER GRAM.
- ANALYZE INVENTORY WEIGHT.
- IDENTIFY HIGH-VALUE INVENTORY.
- FIND PRODUCTS WITH HIGH DISCOUNTS AND LOW STOCK.
- USE ADVANCED SQL TECHNIQUES FOR BUSINESS ANALYSIS.

---

## 🗃️ DATASET

THE PROJECT USES A **ZEPTO PRODUCT DATASET** STORED IN A POSTGRESQL TABLE CALLED `ZEPTO`.

### TABLE STRUCTURE

| COLUMN | DESCRIPTION |
|---|---|
| `ID` | UNIQUE PRODUCT IDENTIFIER |
| `CATEGORY` | PRODUCT CATEGORY |
| `NAME` | PRODUCT NAME |
| `MRP` | MAXIMUM RETAIL PRICE |
| `DISCOUNTPERCENT` | DISCOUNT PERCENTAGE |
| `AVAILABLEQUANTITY` | CURRENT AVAILABLE STOCK |
| `DISCOUNTEDSELLINGPRICE` | SELLING PRICE AFTER DISCOUNT |
| `WEIGHTINGMS` | PRODUCT WEIGHT IN GRAMS |
| `OUTOFSTOCK` | STOCK AVAILABILITY STATUS |
| `QUANTITY` | PRODUCT QUANTITY |

THE TABLE USES A SERIAL PRIMARY KEY FOR PRODUCT IDENTIFICATION AND STORES PRICING, DISCOUNT, INVENTORY, AND PRODUCT INFORMATION.

# 🔍 DATA EXPLORATION

THE FIRST STAGE OF THE PROJECT FOCUSES ON UNDERSTANDING THE DATASET.

### OPERATIONS PERFORMED

- COUNTED THE TOTAL NUMBER OF PRODUCTS.
- VIEWED SAMPLE RECORDS.
- CHECKED FOR NULL VALUES.
- IDENTIFIED UNIQUE PRODUCT CATEGORIES.
- ANALYZED STOCK STATUS.
- IDENTIFIED PRODUCTS APPEARING MULTIPLE TIMES.

FOR EXAMPLE, THE PROJECT CHECKS NULL VALUES ACROSS PRODUCT NAME, CATEGORY, PRICING, WEIGHT, STOCK, AND QUANTITY COLUMNS.

---

# 🧹 DATA CLEANING

DATA CLEANING WAS PERFORMED BEFORE BUSINESS ANALYSIS.

### 1. INVALID PRICES

PRODUCTS WITH `MRP = 0` OR `DISCOUNTEDSELLINGPRICE = 0` WERE IDENTIFIED.

THE RECORD WITH ZERO MRP WAS REMOVED FROM THE DATASET.

### 2. PRICE CONVERSION

THE ORIGINAL PRODUCT PRICES WERE STORED IN **PAISE**.

THE PROJECT CONVERTS THEM INTO **RUPEES** BY DIVIDING THE VALUES BY `100.0`.

# 📊 BUSINESS ANALYSIS

## 🏷️ TOP DISCOUNTED PRODUCTS

THE PROJECT IDENTIFIES THE TOP 10 PRODUCTS BASED ON DISCOUNT PERCENTAGE.

THIS HELPS IDENTIFY PRODUCTS THAT ARE BEING OFFERED AT SIGNIFICANT DISCOUNTS.

---

## 💰 CUSTOMER SAVINGS

THE PROJECT CALCULATES THE ACTUAL DISCOUNT AMOUNT USING:

```sql
MRP - DISCOUNTEDSELLINGPRICE
```

THIS HELPS IDENTIFY PRODUCTS WHERE CUSTOMERS SAVE THE MOST MONEY.

---

## 📦 HIGH-PRICED OUT-OF-STOCK PRODUCTS

THE ANALYSIS IDENTIFIES PRODUCTS WHERE:

- THE PRODUCT IS OUT OF STOCK.
- MRP IS GREATER THAN ₹300.

THIS CAN HELP IDENTIFY HIGH-VALUE PRODUCTS THAT MAY REQUIRE RESTOCKING.

---

## 💵 CATEGORY-WISE REVENUE

ESTIMATED REVENUE IS CALCULATED FOR EACH CATEGORY USING:

```text
DISCOUNTED SELLING PRICE × AVAILABLE QUANTITY
```

THIS HELPS IDENTIFY WHICH PRODUCT CATEGORIES HAVE THE HIGHEST POTENTIAL REVENUE BASED ON CURRENT INVENTORY.

---

## 🛒 HIGH-MRP LOW-DISCOUNT PRODUCTS

THE PROJECT IDENTIFIES PRODUCTS WITH:

- MRP GREATER THAN ₹500
- DISCOUNT LESS THAN 10%

THIS CAN HELP UNDERSTAND PRODUCTS THAT MAINTAIN HIGH PRICES DESPITE HAVING LOW DISCOUNTS.

---

## 📈 CATEGORY-WISE DISCOUNT ANALYSIS

THE PROJECT CALCULATES THE **AVERAGE DISCOUNT PERCENTAGE FOR EACH CATEGORY** AND IDENTIFIES THE TOP 5 CATEGORIES WITH THE HIGHEST AVERAGE DISCOUNTS.

THIS CAN PROVIDE USEFUL INFORMATION FOR PRICING AND MARKETING ANALYSIS.

---

# ⚖️ PRODUCT VALUE ANALYSIS

THE PROJECT CALCULATES **PRICE PER GRAM** FOR PRODUCTS WEIGHING AT LEAST 100G.

```text
PRICE PER GRAM =
DISCOUNTED SELLING PRICE / PRODUCT WEIGHT
```

PRODUCTS ARE THEN SORTED FROM THE LOWEST PRICE PER GRAM TO THE HIGHEST.

THIS PROVIDES A SIMPLE WAY TO COMPARE VALUE BETWEEN PRODUCTS.

---

# 📦 WEIGHT CATEGORY ANALYSIS

PRODUCTS ARE CLASSIFIED INTO THREE GROUPS BASED ON WEIGHT:

- **LOW** → LESS THAN 1000G
- **MEDIUM** → 1000G TO LESS THAN 5000G
- **BULK** → 5000G OR MORE

THIS HELPS UNDERSTAND THE DISTRIBUTION OF PRODUCT PACK SIZES.

---

# 🏭 INVENTORY ANALYSIS

THE PROJECT CALCULATES THE TOTAL INVENTORY WEIGHT FOR EACH CATEGORY USING:

```text
PRODUCT WEIGHT × AVAILABLE QUANTITY
```

THIS CAN HELP WITH INVENTORY MANAGEMENT AND WAREHOUSE PLANNING.

---

# 🚀 ADVANCED SQL ANALYSIS

THE PROJECT ALSO USES ADVANCED SQL TECHNIQUES.

### SUBQUERIES

PRODUCTS WITH DISCOUNTS HIGHER THAN THE OVERALL AVERAGE DISCOUNT ARE IDENTIFIED USING A SUBQUERY.

### COMMON TABLE EXPRESSIONS

A CTE IS USED TO CALCULATE CATEGORY-WISE AVERAGE DISCOUNTS.

```sql
WITH CATEGORY_DISCOUNT AS (...)
```

THIS MAKES THE ANALYSIS MORE STRUCTURED AND READABLE.

### ROW_NUMBER()

`ROW_NUMBER()` IS USED TO FIND THE **TOP 3 DISCOUNTED PRODUCTS WITHIN EACH CATEGORY**.

THIS ALLOWS PRODUCTS TO BE RANKED INDEPENDENTLY INSIDE EACH CATEGORY.

### RANK()

`RANK()` IS USED TO RANK PRODUCTS BASED ON DISCOUNT WITHIN THEIR CATEGORY.

THIS HELPS COMPARE PRODUCTS AGAINST OTHER PRODUCTS IN THE SAME CATEGORY.

### TOP PRODUCTS BY DISCOUNT AMOUNT

THE PROJECT USES CTEs AND `ROW_NUMBER()` TO IDENTIFY THE TOP 3 PRODUCTS WITH THE HIGHEST **ABSOLUTE DISCOUNT AMOUNT** WITHIN EACH CATEGORY.

---

# 💎 INVENTORY VALUE ANALYSIS

THE PROJECT CALCULATES THE CURRENT INVENTORY VALUE USING:

```text
DISCOUNTED SELLING PRICE × AVAILABLE QUANTITY
```

THE TOP 10 PRODUCTS WITH THE HIGHEST INVENTORY VALUE ARE IDENTIFIED.

THIS HELPS SHOW WHICH PRODUCTS HAVE THE MOST MONEY CURRENTLY TIED UP IN INVENTORY.

---

# ⚠️ HIGH DISCOUNT + LOW STOCK

THE PROJECT IDENTIFIES PRODUCTS WHERE:

```text
DISCOUNT >= 30%
AND
AVAILABLE QUANTITY <= 3
```

THESE PRODUCTS HAVE BOTH **HIGH DISCOUNTS AND LOW AVAILABLE STOCK**, MAKING THEM IMPORTANT FOR INVENTORY PLANNING.
